# Changelog

Releases are named "One Click Armor Set V&lt;n&gt;" (tag `v<n>`). Each section is that release's notes.

## V4 (2026-10-12)

- Added Randomize Armor: a Mod Bindings Menu key that puts on random armor in the Armory, Character menu and Hellpod armor lists.
- Added the Randomization Mode option: a random whole set, or a random helmet, armor, cape and player card from everything you own.
- Added the Keep Armor Weight option: random armor stays in the weight class you are wearing.
- Sets now cover every warbond page, Superstore set and special set (131 sets, 456 items), including the first warbonds' player cards.
- B-01 Tactical sets include the Foesmasher cape and Solid Black player card; DP-00 Tactical includes the Veridical Ideology cape and Solid Black.
- Fixed: the Agent of Oblivion player card was in the FS-61 Dreadnought set instead of EX-00 Prototype X.
- Fixed: the mod could stop working when another mod declared the same Windows functions differently.
- New texts translated into every game language.

## V3 (2026-10-04)

- EQUIP SET now works in the Hellpod loadout's helmet, armor and cape lists, player card included.
- When the whole set is already equipped, the button shows "(4/4)" and is disabled.
- The button equips at most once every 0.5 s.
- Set names leave out the armor designation ("EQUIP KODIAK SET").
- Translated into every game language.
- After game updates, the mod searches game.dll for its code. Anything not found disables only the feature that needs it.

## V2 (2026-09-29)

- Superstore capes and player cards are now matched to their armor sets (129 sets, 417 items).
- Fixed: the Liberty's Herald and Cresting Honor sets never showed the button.

## V1

- First release: an EQUIP SET button in the ship Armory and Character menus, with Mod Options Menu toggles for the cape and the card and a Mod Bindings Menu key.
